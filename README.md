# SOC Networking Lab

## Project Overview

This repository documents my two-week networking practice journey focused on developing foundational networking knowledge and practical skills relevant to Security Operations Centre (SOC) analysis.

The project covers networking fundamentals, network configuration, packet analysis, Nmap scanning, VLANs, firewall logs and basic security investigations.

## Learning Objectives

* Understand the OSI and TCP/IP models.
* Identify IP addresses, ports and network protocols.
* Practise subnetting and network configuration.
* Analyse network traffic using Wireshark.
* Understand and investigate Nmap port-scanning activity.
* Learn network segmentation and VLAN concepts.
* Interpret firewall logs and identify potentially suspicious activity.
* Develop SOC investigation and reporting skills.

## Practical Work Completed

### Network Configuration

Inspected network interfaces, IP addresses, subnet masks and routing information.

### Wireshark

Analysed sample packet captures and investigated TCP conversations, protocols and network communication.

### Nmap

Performed localhost scanning, host discovery and TCP service detection within a controlled lab environment.

### VLANs

Studied logical network segmentation, VLAN IDs, access ports, trunk ports and inter-VLAN routing.

### Firewall Logs

Studied firewall actions, common network ports and SOC investigation procedures.

## Key Skills Developed

* Network traffic analysis.
* TCP/IP fundamentals.
* IP addressing and subnetting.
* Port and protocol identification.
* Nmap scanning.
* Wireshark packet analysis.
* Basic network security investigation.
* Security documentation and reporting.

## Safety and Lab Environment

Practical scanning activities were restricted to localhost and the configured VirtualBox host-only network.

Downloaded sample packet captures were used for traffic analysis.

No intentional scanning of external networks was performed.

## Conclusion

This project strengthened my understanding of networking fundamentals and introduced practical techniques used by SOC analysts when investigating network activity.

It provided an opportunity to work with industry-relevant tools, analyse network traffic, interpret scanning results and document security findings.
